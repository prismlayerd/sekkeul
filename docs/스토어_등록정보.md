콘솔에 그대로 붙여 넣으면 되는 문안입니다.

**자세한 설명은 -습니다 체입니다** (2026-08-24, 사용자 원고 기준). 짧은 문장은
-해요 체가 친근한데, 한 화면을 넘기는 긴 글에서는 -습니다 체가 덜 지칩니다.
간단한 설명·스크린샷 문구는 -해요 체 그대로 둡니다 — 거긴 한 줄이라 다릅니다.

> **근거 없는 문장은 안 씁니다.** 아래 숫자는 전부 저장소에서 센 것입니다 —
> 혜택 54개(`benefit_screen.dart`의 `_Benefit(` 54개), 계산기 56종
> (`calculator_screen.dart`의 `_Calc(` 57개 − 생성자 선언 1개), 양식 19종
> (`assets/forms/` PDF 19개). "인터넷 권한이 없다"는 릴리스
> `AndroidManifest.xml`에 `INTERNET`이 없다는 뜻이고, 스토어 권한 목록에서
> 사용자가 직접 확인할 수 있습니다. 세 숫자 모두 v1.1.0+9 때와 같습니다 —
> 다시 셌고 안 바뀌었습니다.

**+9에서 무엇이 바뀌었나** (커밋 28개). 문안을 고친 이유가 여기 있습니다.

| 바뀐 것 | 문안에 미치는 영향 |
|---|---|
| 경정청구가 **공식 서식을 채웁니다** — 국세·지방세 둘 다 | 「안내해요」 → 「서식을 채워드려요」로 승격 |

## 4. 스크린샷

### 목업 배경은 **잉크(#1F1F1F)** 입니다. 종이 아닙니다.

앱 화면이 거의 흰 종이라, 목업 배경까지 종이로 깔면 스크린샷의 경계가 사라져서
무엇이 앱이고 무엇이 배경인지 안 보입니다. 어두운 잉크 바탕에 흰 문구를 얹고
가운데에 화면을 놓으면, 흰 화면이 액자 안의 그림처럼 떠오릅니다.

```
┌──────────────────────────┐  ← 1080 × 1920 (9:16)
│                          │
│   적어 두면 그대로          │  ← 흰 글자, 두 줄
│   공제 계산으로 이어져요      │
│                          │
│   ┌──────────────┐       │
│   │              │       │
│   │  (앱 스크린샷)  │       │  ← 흰 화면이 잉크 위에 뜬다
│   │              │       │
│   └──────────────┘       │
│                          │
└──────────────────────────┘
     바탕 #1F1F1F
```

Play는 휴대전화 스크린샷을 **16:9 또는 9:16**으로 요구합니다. 9:16은 정확히
**0.5625**인데 요즘 폰은 20:9(약 0.45)라서 원본 그대로는 비율이 안 맞습니다.
어차피 맞춰야 하니 위 목업으로 한 번에 해결하는 게 낫습니다.
**원본 PNG를 폴더에 넣어주시면 제가 목업으로 만들어 드립니다.**

### 기존 5장 — 홈이 바뀌어서 두 장을 다시 찍어야 합니다

홈 1장의 절 구성이 `01 수입 · 02 다른 소득 · 03 지출 · 04 놓치기 쉬운 공제 ·
05 리마인더`로 바뀌었고, 세무 도구는 **2장(옆으로 넘김)**으로 옮겼습니다.

| # | 화면 | 문구 | 상태 |
|---|---|---|---|
| 1 | 홈 · 이번 달 (직장인) | **이번 달 얼마 벌고 썼는지<br>한 장으로 보여요** | **다시 찍기** — 절 구성이 바뀜 |
| 2 | 챙길 알림 | **미루지 않게<br>때맞춰 알려드려요** | 일정 이름만 바꿔주세요 |
| 3 | 홈 · 도구 | **혼자서도 신고할 수 있게<br>순서대로 짚어드려요** | **다시 찍기** — 이제 홈 2장입니다 |
| 4 | 가계부 달력 (빈 달) | **결제수단까지 나눠 적으면<br>카드공제 계산이 따라와요** | 그대로 씁니다 |
| 5 | 설정 | **계정도 서버도 없어요<br>지우면 정말로 사라져요** | 그대로 씁니다 |

**4번은 비워 둔 화면을 그대로 씁니다.** 그래서 문구가 **적힌 것을 가리키면 안
됩니다** — 「적어 두면 그대로 이어져요」라고 쓰면 적힌 게 없어서 앞뒤가 안 맞습니다.
대신 화면에 **실제로 보이는 것**을 가리킵니다: 하단 범례의
`＋수익 · ■신용카드 · ●체크·현금 · ▲기타`.

**2번 주의:** 「강아지 산책」·「점심 약속」은 실제 일정입니다. 예시로 바꿔주세요.
