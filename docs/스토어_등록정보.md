# 세끌 — Play 스토어 등록정보 (v1.1.0+10)

콘솔에 그대로 붙여 넣으면 되는 문안입니다. 말투는 **-해요 체**로 통일했습니다.

> **근거 없는 문장은 안 씁니다.** 아래 숫자는 전부 저장소에서 센 것입니다 —
> 혜택 54개(`benefit_screen.dart`의 `_Benefit(` 54개), 계산기 56종
> (`calculator_screen.dart`의 `_Calc(` 57개 − 생성자 선언 1개), 양식 19종
> (`assets/forms/` PDF 19개). "인터넷 권한이 없다"는 릴리스
> `AndroidManifest.xml`에 `INTERNET`이 없다는 뜻이고, 스토어 권한 목록에서
> 사용자가 직접 확인할 수 있습니다. 세 숫자 모두 v1.1.0+9 때와 같습니다 —
> 다시 셌고 안 바뀌었습니다.

**+9에서 무엇이 바뀌었나** (커밋 28개). 문안을 고친 이유가 여기 있습니다.

| 바뀐 것 | 문안에 미치는 영향 |
|---|---|
| 경정청구가 **공식 서식을 채웁니다** — 국세·지방세 둘 다 | 「안내해요」 → 「서식을 채워드려요」로 승격 |
| 제출 방식을 **두 갈래**로 고릅니다 (프린트 / 홈택스 가이드) | 새 문단 |
| 홈에 **04 놓치기 쉬운 공제** — 간소화에 안 나오는 것만 | 「놓친 공제」 문단을 정확하게 |
| 홈에 **02 다른 소득** — 부수입이 신고 의무를 만드는지 판정 | 새 문단 |
| **소급 입력(백필)** — 연중에 깔아도 1월부터 채웁니다 | 새 문단 |
| 전통시장·대중교통·도서공연을 가계부가 직접 받음 | 카드공제 문단 보강 |
| 앱 안에서 **글자 크기** 선택 (보통·크게·아주 크게) | 새 줄 |
| 장부 만들기가 **이득인지 먼저** 말함 | 프리랜서 문단 보강 |

## 1. 앱 이름 (30자 이내)

```
세끌 : 환급 계산기·절세·연말정산·종소세
```

**27자 → 23자.** 지금 콘솔에 올라간 이름은 `·가계부`까지 붙어 다섯 덩어리인데,
검색결과에서는 뒤가 잘리고 아이콘 옆에서는 읽는 게 아니라 훑어집니다. 가계부는
수단이지 사람들이 검색하는 말이 아니라 뺐습니다.

바꾸기 싫으시면 지금 이름 그대로도 규격 위반은 없습니다.

## 2. 간단한 설명 (80자 이내)

검색결과와 앱 상단에 노출되는 유일한 문장입니다.

```
소득 정보가 기기 밖으로 안 나가요. 놓친 공제 찾기부터 5월 종소세까지 챙겨드려요.
```

*(공백 포함 47자)*

**온디바이스를 앞으로 뺐습니다.** 세금 앱을 깔 때 가장 큰 망설임이 "내 연봉을 왜
저기다 올려야 하지"인데, 이걸 첫 문장에서 지우는 게 환급을 약속하는 것보다 셉니다.
게다가 이 문장은 **증명할 수 있습니다** — 권한 목록에 인터넷이 없으니까요.

### 대안 — 환급을 앞세우고 싶다면

```
놓친 공제를 찾아주고, 5월 종소세까지 챙겨드려요. 소득 정보는 기기 밖으로 안 나가요.
```

## 3. 자세한 설명 (4000자 이내)

```
세금 이야기는 어렵고, 어려우면 미루게 되죠.
세끌은 어려운 말을 걷어내고 "지금 뭘 하면 되는지"만 알려드리는 앱이에요.

■ 서버가 없어요. 정말로 없어요.

세끌에는 인터넷 권한이 아예 없어요.
위 권한 목록을 직접 확인해 보세요 — 알림, 진동, 지문 잠금뿐이에요.

회원가입도, 로그인도, 계정도 없어요.
연봉도 지출도 전부 휴대폰 안에만 저장돼요. 보낼 곳이 없으니 보낼 수가 없어요.
계산도 전부 기기 안에서 해요. 비행기 모드로도 똑같이 돌아가요.
휴대폰을 바꾸면 데이터도 같이 사라져요 — 어디에도 사본이 없다는 뜻이에요.

세금 앱에 연봉을 넣기 망설여지셨다면, 그 걱정을 없애려고 이렇게 만들었어요.

■ 가계부에 적은 게 그대로 세금 계산이 돼요

여기가 세끌의 핵심이에요. 가계부 따로, 세금 계산기 따로가 아니에요.

달력에 지출을 적으면 결제수단(신용카드 / 체크·현금 / 기타)별로 쌓여요.
그러면 홈에서 신용카드 소득공제 문턱(연봉의 25%)까지 얼마 남았는지 보여드려요.
문턱을 넘는 순간부터는 체크카드가 두 배로 공제되니까, 그때부터 결제수단을
바꾸시라고 알려드려요. 연말정산 때 몰아서 후회하지 않게요.

전통시장·대중교통·도서공연은 공제율이 따로예요. 적을 때 표시해두면
그 몫으로 따로 쌓여요. 보험료나 통신비처럼 카드로 긁어도 공제가 안 되는 건
문턱 계산에서 알아서 빼드려요.

■ 중간에 깔아도 1월부터 채울 수 있어요

7월에 앱을 깔았다고 1월부터 6월이 사라지는 게 아니에요.
지난 달들을 한 화면에서 몰아서 채울 수 있어요.
다 채우기 전까지는 연간 숫자를 함부로 내놓지 않아요 —
반쪽짜리 계산을 정답처럼 보여드리지 않으려고요.

■ 나에게 맞는 계산을 해드려요

직장인 · N잡러 · 프리랜서, 세 유형 중에 고르면 화면이 통째로 바뀌어요.
같은 "세금"이라도 직장인은 연말정산이고 프리랜서는 5월 종합소득세니까요.
N잡러는 근로소득과 사업소득을 합산해서 한계세율까지 보여드려요.

유형을 바꿔도 가계부와 내 정보는 그대로 따라가요. 다시 적을 필요 없어요.

■ 월급 말고 들어온 돈이 있으면, 신고해야 하는지 알려드려요

부업 수입, 강의료, 이자·배당, 월세.
이게 5월 신고 의무를 만드는 금액인지 아닌지가 소득마다 다른데,
그 기준을 앱이 대신 봐드려요.

사업소득은 1원이라도 신고 대상이에요. 기타소득은 소득금액 300만원,
이자·배당은 2,000만원이 갈림길이고요.
주택임대는 1주택이면 대개 비과세라 신고 안 하셔도 돼요 —
없는 의무를 만들어 겁주지 않아요.

부업이 커져서 유형을 옮기는 게 맞으면 그것도 말씀드려요.

■ 프리랜서는 평소에 적은 게 곧 장부예요

적어둔 수입과 경비가 국세청 간편장부 서식으로 그대로 나가요.
장부만 갖추면 무기장가산세(산출세액의 20%)가 사라지는데,
그걸 위해 따로 정리할 게 없어요.

장부를 쓰는 게 정말 이득인지부터 먼저 계산해서 알려드려요.
경비가 적으면 추계신고가 나을 수도 있거든요. 무조건 권하지 않아요.

■ 놓치기 쉬운 공제를 짚어드려요

홈택스 간소화에 자동으로 안 나오는 것들이 있어요.
안경·콘택트렌즈, 산후조리원, 교복, 취학 전 학원비, 종교단체 기부금 같은 것들요.

간소화에 이미 뜨는 건 안 물어봐요. 홈택스가 해주는 걸 앱이 또 시키면
그게 더 번거로우니까요. 놓치는 것만 챙겨드려요.

■ 이미 지나간 5년치도 돌려받을 수 있어요

작년에, 재작년에 놓친 공제가 있으면 경정청구로 돌려받을 수 있어요.
세끌이 국세·지방세 경정청구서를 앱이 아는 칸까지 채워드려요.

받는 방법은 두 가지 중에 고르시면 돼요.
① 채워진 서식을 받아서 프린트해 세무서에 내기
② 홈택스에 뭘 어디에 넣고 무슨 서류를 붙일지, 내 항목 이름으로 안내받기

■ 혼자서도 신고할 수 있게 순서대로 짚어드려요

① 놓친 공제부터 찾고
② 신고서를 자동으로 채워 미리 보고
③ 홈택스 어디에 무엇을 넣을지 1:1로 안내받아요.

내 정보 중에 아직 안 채운 게 있으면 "이게 비어서 이 숫자는 정확하지 않아요"라고
먼저 말씀드려요. 빈 칸을 모른 척하고 그럴듯한 숫자를 보여드리지 않아요.
```

## 4. 스크린샷

### 목업 배경은 **잉크(#1F1F1F)** 입니다. 종이 아닙니다.

앱 화면이 거의 흰 종이라, 목업 배경까지 종이로 깔면 스크린샷의 경계가 사라져서
무엇이 앱이고 무엇이 배경인지 안 보입니다. 어두운 잉크 바탕에 흰 문구를 얹고
가운데에 화면을 놓으면, 흰 화면이 액자 안의 그림처럼 떠오릅니다.

```
┌──────────────────────────┐  ← 1080 × 1920 (9:16)
│                          │
│   적어 두면 그대로          │  ← 흰 글자, 두 줄
│   공제 계산으로 이어져요      │
│                          │
│   ┌──────────────┐       │
│   │              │       │
│   │  (앱 스크린샷)  │       │  ← 흰 화면이 잉크 위에 뜬다
│   │              │       │
│   └──────────────┘       │
│                          │
└──────────────────────────┘
     바탕 #1F1F1F
```

Play는 휴대전화 스크린샷을 **16:9 또는 9:16**으로 요구합니다. 9:16은 정확히
**0.5625**인데 요즘 폰은 20:9(약 0.45)라서 원본 그대로는 비율이 안 맞습니다.
어차피 맞춰야 하니 위 목업으로 한 번에 해결하는 게 낫습니다.
**원본 PNG를 폴더에 넣어주시면 제가 목업으로 만들어 드립니다.**

### 기존 5장 — 홈이 바뀌어서 두 장을 다시 찍어야 합니다

홈 1장의 절 구성이 `01 수입 · 02 다른 소득 · 03 지출 · 04 놓치기 쉬운 공제 ·
05 리마인더`로 바뀌었고, 세무 도구는 **2장(옆으로 넘김)**으로 옮겼습니다.

| # | 화면 | 문구 | 상태 |
|---|---|---|---|
| 1 | 홈 · 이번 달 (직장인) | **이번 달 얼마 벌고 썼는지<br>한 장으로 보여요** | **다시 찍기** — 절 구성이 바뀜 |
| 2 | 챙길 알림 | **미루지 않게<br>때맞춰 알려드려요** | 일정 이름만 바꿔주세요 |
| 3 | 홈 · 도구 | **혼자서도 신고할 수 있게<br>순서대로 짚어드려요** | **다시 찍기** — 이제 홈 2장입니다 |
| 4 | 가계부 달력 (빈 달) | **결제수단까지 나눠 적으면<br>카드공제 계산이 따라와요** | 그대로 씁니다 |
| 5 | 설정 | **계정도 서버도 없어요<br>지우면 정말로 사라져요** | 그대로 씁니다 |

**4번은 비워 둔 화면을 그대로 씁니다.** 그래서 문구가 **적힌 것을 가리키면 안
됩니다** — 「적어 두면 그대로 이어져요」라고 쓰면 적힌 게 없어서 앞뒤가 안 맞습니다.
대신 화면에 **실제로 보이는 것**을 가리킵니다: 하단 범례의
