# 세끌 — Play 스토어 등록정보 (v1.1.0+9)

콘솔에 그대로 붙여 넣으면 되는 문안입니다. 말투는 **-해요 체**로 통일했습니다.

> **근거 없는 문장은 안 씁니다.** 아래 숫자는 전부 저장소에서 센 것입니다 —
> 혜택 54개(`benefit_screen.dart`), 계산기 56개(`calculator_screen.dart`),
> 양식 19종(`assets/forms/`), 화면 89개. "인터넷 권한이 없다"는
> `AndroidManifest.xml`에 `INTERNET`이 릴리스에 안 들어 있다는 뜻이고,
> 스토어 권한 목록에서 사용자가 직접 확인할 수 있습니다.

---

## 1. 앱 이름 (30자 이내)

```
세끌 : 환급 계산기·절세·연말정산·종소세
```

**27자 → 24자로 줄였습니다.** 지금 이름은 `·가계부`까지 붙어 다섯 덩어리인데,
검색결과에서는 뒤가 잘려 나가고 아이콘 옆에서는 읽는 게 아니라 훑어집니다.
가계부는 수단이지 사람들이 검색하는 말이 아니라 뺐습니다 — 자세한 설명에서 다룹니다.

바꾸기 싫으시면 지금 이름 그대로 둬도 규격 위반은 없습니다.

---

## 2. 간단한 설명 (80자 이내)

검색결과와 앱 상단에 노출되는 유일한 문장입니다.

```
놓친 공제를 찾아주고, 5월 종소세까지 챙겨드려요. 소득 정보는 기기 밖으로 안 나가요.
```

*(공백 포함 45자)*

**왜 이 문장인가.** 앞 절은 설치 이유(환급), 뒤 절은 경쟁 앱과 다른 점(온디바이스)
입니다. 세금 앱을 깔 때 가장 큰 망설임이 "내 소득을 왜 저기다 올려야 하지"인데,
그걸 첫 문장에서 지웁니다.

### 대안 — 환급을 더 앞세우고 싶다면

```
연말정산에서 놓친 공제, 5월 종소세, 경정청구까지. 서버 없이 기기 안에서 계산해요.
```

## 3. 자세한 설명 (4000자 이내)

```
세금 이야기는 어렵고, 어려우면 미루게 되죠.
세끌은 어려운 말을 걷어내고 "지금 뭘 하면 되는지"만 알려드리는 앱이에요.

■ 소득 정보가 기기 밖으로 나가지 않아요

세끌에는 인터넷 권한이 아예 없어요. 회원가입도, 로그인도 없어요.
연봉도 지출도 전부 휴대폰 안 SQLite에만 저장되고, 보낼 곳이 없으니 보낼 수가 없어요.
위 권한 목록에서 직접 확인해 보세요 — 알림과 지문 잠금 권한밖에 없어요.

■ 나에게 맞는 계산을 해드려요

직장인 · N잡러 · 프리랜서, 세 유형 중에 고르면 화면이 통째로 바뀌어요.
같은 "세금"이라도 직장인은 연말정산이고 프리랜서는 5월 종합소득세니까요.
N잡러는 근로소득과 사업소득을 합산해서 한계세율까지 보여드려요.

■ 이번 달 얼마 벌고 얼마 썼는지, 홈에서 바로 보여요

앱을 열면 이번 달 수령액과 지출이 명세서 한 장처럼 정리돼 있어요.
지출 목표를 정해두면 얼마나 아꼈는지, 신용카드 공제 문턱까지 얼마 남았는지
막대로 보여드려요. 문턱을 넘으면 그때부터 올해 예상 환급이 쌓이기 시작해요.

■ 놓친 공제를 찾아드려요

연말정산에 안 넣은 공제가 있는지 짚어드리고, 지난 5년 안에 놓친 게 있으면
경정청구로 돌려받는 방법까지 안내해요.

■ 5월 종합소득세, 처음이어도 괜찮아요

① 종소세 진단으로 낼 세금을 먼저 계산하고
② 가상 신고서로 채워진 결과를 미리 보고
③ 홈택스 어디에 무엇을 넣을지 1:1로 안내받아요.
회사를 안 거치고 직접 신고하는 분들을 위해 서류 체크리스트와 간편장부도 있어요.

■ 계산기 56종

연봉 실수령액, 4대 보험료, 퇴직금, 주휴수당, 전세 vs 월세, 대출 상환 스케줄,
양도소득세, 상속·증여세까지. 궁금할 때 꺼내 쓰는 계산기를 모아뒀어요.

■ 정부 혜택 54가지

근로장려금, 에너지 바우처, 청년 지원, 디딤돌·버팀목 대출처럼
알면 받는데 몰라서 못 받는 것들을 모았어요.
금액과 조건은 원문 주소와 확인한 날짜를 함께 적어뒀어요.

■ 자주 쓰는 양식 19종

연말정산·종합소득세·경정청구 서식을 앱 안에서 바로 열 수 있어요.

■ 챙겨야 할 때 알려드려요

지출 목표를 넘었을 때, 며칠째 기록을 안 했을 때, 고정지출 결제일이 왔을 때
알림을 보내드려요. 직접 만드는 알림도 추가할 수 있어요.

―――――――――――――――

세끌은 세무 대리가 아니에요. 계산 결과는 참고용이고,
실제 신고는 홈택스나 세무 전문가를 통해 확인해 주세요.

문의 · 오류 제보: (이메일 주소를 적어주세요)
```

## 4. 스크린샷

### 규격 주의 — 지금 찍은 것 그대로는 못 올릴 수 있어요

Play는 휴대전화 스크린샷을 **16:9 또는 9:16**으로 요구합니다.
9:16은 정확히 **0.5625**인데, 요즘 폰은 대부분 20:9(약 0.45)라서 원본 그대로는
비율이 안 맞습니다. 올려 보고 거절당하면 알려주세요 —
종이 배경으로 위아래를 채워 **1080×1920**으로 맞춰 드리겠습니다.

### 보내주신 3장에 붙일 문구

| # | 화면 | 문구 |
|---|---|---|
| 1 | 홈 · 이번 달 | **이번 달 얼마 벌고 썼는지<br>한 장으로 보여요** |
| 2 | 챙길 알림 | **미루지 않게<br>때맞춰 알려드려요** |
| 3 | 홈 · 도구와 문답 | **5월 종소세,<br>세 단계면 끝나요** |

문구는 **위쪽에, 두 줄로**, 화면 이미지 위에 얹지 말고 여백에 두세요.
Play 목록에서는 썸네일 크기라 화면 안 글자는 안 읽히고 문구만 읽힙니다.

### 더 찍어주실 화면 — 우선순위대로

**① 가계부 달력 (필수)** — 홈 → 「가계부 열기」
이 앱에서 가장 눈에 띄는 화면이고, 방금 빨간날·오늘 밑줄까지 고쳐서 지금이 제일 예쁩니다.
지출이 며칠 찍혀 있는 달로 찍어주세요. 텅 빈 달은 앱이 비어 보입니다.
> **하루하루 적으면<br>달력이 알아서 정리해요**

**② 종소세 진단 결과 (필수)** — 홈 2장 → 「1 종소세 진단」 끝까지
설치 이유가 여기 있습니다. 계산이 끝나 **금액이 나온 화면**이어야 합니다.
입력 폼이 아니라 결과입니다.
> **낼 세금이 얼마인지<br>먼저 알려드려요**

**③ 계산기 탭 목록 (필수)** — 하단 「계산기」
56종이 쭉 늘어선 목록. 양이 곧 메시지입니다.
> **연봉 실수령액부터 퇴직금까지<br>계산기 56종**

**④ 혜택 탭 목록** — 하단 「혜택」
54가지 정부 지원. 여기도 목록이 그대로 설득입니다.
> **몰라서 못 받는 정부 혜택<br>54가지를 모았어요**

**⑤ 유형 전환이 보이는 홈 (프리랜서 또는 N잡러)**
스크린샷 3이 이미 프리랜서 2장이니, 이건 **1장**을 프리랜서로 찍어주세요.
직장인과 다른 화면이 나온다는 걸 보여줍니다.
> **직장인 · N잡러 · 프리랜서<br>고르면 화면이 바뀌어요**

**⑥ 놓친 공제 진단 결과** — 「빠진 공제 항목 찾기」
> **연말정산에서 놓친 공제,<br>5년 안이면 돌려받아요**

①~③까지만 더 있어도 **6장**이라 충분합니다. ④~⑥은 여유 되실 때요.

### 찍지 말아야 할 것

- **빈 화면.** 「기록 없음」이 보이면 안 씁니다. 지금 스크린샷 1이 잘 된 예입니다 — 숫자가 들어 있죠
- **설정·내 정보 화면.** 아무도 이걸 보고 설치하지 않습니다
- **개인 정보.** 스크린샷 2의 「강아지 산책」·「점심 약속」은 귀엽지만 실제 일정입니다. 예시로 바꿔주세요
