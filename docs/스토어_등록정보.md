# 세끌 — Play 스토어 등록정보 (v1.1.0+9)

콘솔에 그대로 붙여 넣으면 되는 문안입니다. 말투는 **-해요 체**로 통일했습니다.

> **근거 없는 문장은 안 씁니다.** 아래 숫자는 전부 저장소에서 센 것입니다 —
> 혜택 54개(`benefit_screen.dart`), 계산기 56개(`calculator_screen.dart`),
> 양식 19종(`assets/forms/`). "인터넷 권한이 없다"는 릴리스
> `AndroidManifest.xml`에 `INTERNET`이 없다는 뜻이고, 스토어 권한 목록에서
> 사용자가 직접 확인할 수 있습니다. 가계부↔세금 연결은
> `home_screen.dart:1264`(카드공제 문턱)와
> `bookkeeping_guide_screen.dart`(간편장부 CSV)입니다.

## 1. 앱 이름 (30자 이내)

```
세끌 : 환급 계산기·절세·연말정산·종소세
```

**27자 → 24자.** 지금 이름은 `·가계부`까지 붙어 다섯 덩어리인데, 검색결과에서는
뒤가 잘리고 아이콘 옆에서는 읽는 게 아니라 훑어집니다. 가계부는 수단이지 사람들이
검색하는 말이 아니라 뺐습니다.

바꾸기 싫으시면 지금 이름 그대로도 규격 위반은 없습니다.

## 2. 간단한 설명 (80자 이내)

검색결과와 앱 상단에 노출되는 유일한 문장입니다.

```
소득 정보가 기기 밖으로 안 나가요. 놓친 공제 찾기부터 5월 종소세까지 챙겨드려요.
```

*(공백 포함 45자)*

**온디바이스를 앞으로 뺐습니다.** 세금 앱을 깔 때 가장 큰 망설임이 "내 연봉을 왜
저기다 올려야 하지"인데, 이걸 첫 문장에서 지우는 게 환급을 약속하는 것보다 셉니다.
게다가 이 문장은 **증명할 수 있습니다** — 권한 목록에 인터넷이 없으니까요.

### 대안 — 환급을 앞세우고 싶다면

```
놓친 공제를 찾아주고, 5월 종소세까지 챙겨드려요. 소득 정보는 기기 밖으로 안 나가요.
```

```

회원가입도, 로그인도, 계정도 없어요.
연봉도 지출도 전부 휴대폰 안에만 저장돼요. 보낼 곳이 없으니 보낼 수가 없어요.
계산도 전부 기기 안에서 해요. 비행기 모드로도 똑같이 돌아가요.
휴대폰을 바꾸면 데이터도 같이 사라져요 — 어디에도 사본이 없다는 뜻이에요.

세금 앱에 연봉을 넣기 망설여지셨다면, 그 걱정을 없애려고 이렇게 만들었어요.

여기가 세끌의 핵심이에요. 가계부 따로, 세금 계산기 따로가 아니에요.

달력에 지출을 적으면 결제수단(신용카드 / 체크·현금 / 기타)별로 쌓여요.

바꾸시라고 알려드려요. 연말정산 때 몰아서 후회하지 않게요.

프리랜서라면 적어둔 수입과 경비가 국세청 간편장부 서식으로 그대로 나가요.
장부만 갖추면 무기장가산세(산출세액의 20%)가 사라지는데,
그걸 위해 따로 정리할 게 없어요. 평소에 적은 게 곧 장부예요.

■ 나에게 맞는 계산을 해드려요

직장인 · N잡러 · 프리랜서, 세 유형 중에 고르면 화면이 통째로 바뀌어요.
같은 "세금"이라도 직장인은 연말정산이고 프리랜서는 5월 종합소득세니까요.
N잡러는 근로소득과 사업소득을 합산해서 한계세율까지 보여드려요.

■ 이번 달 얼마 벌고 썼는지, 홈에서 바로 보여요

앱을 열면 이번 달 수령액과 지출이 명세서 한 장처럼 정리돼 있어요.

경정청구로 돌려받는 방법까지 안내해요.

② 신고서를 자동으로 채워 미리 보고
```

## 4. 스크린샷

### 목업 배경은 **잉크(#1F1F1F)** 입니다. 종이 아닙니다.

앱 화면이 거의 흰 종이라, 목업 배경까지 종이로 깔면 스크린샷의 경계가 사라져서
무엇이 앱이고 무엇이 배경인지 안 보입니다. 어두운 잉크 바탕에 흰 문구를 얹고
가운데에 화면을 놓으면, 흰 화면이 액자 안의 그림처럼 떠오릅니다.

```
┌──────────────────────────┐  ← 1080 × 1920 (9:16)
│                          │
│   적어 두면 그대로          │  ← 흰 글자, 두 줄
│   공제 계산으로 이어져요      │
│                          │
│   ┌──────────────┐       │
│   │              │       │
│   │  (앱 스크린샷)  │       │  ← 흰 화면이 잉크 위에 뜬다
│   │              │       │
│   └──────────────┘       │
│                          │
└──────────────────────────┘
     바탕 #1F1F1F
```

Play는 휴대전화 스크린샷을 **16:9 또는 9:16**으로 요구합니다. 9:16은 정확히
**0.5625**인데 요즘 폰은 20:9(약 0.45)라서 원본 그대로는 비율이 안 맞습니다.
어차피 맞춰야 하니 위 목업으로 한 번에 해결하는 게 낫습니다.
**원본 PNG를 폴더에 넣어주시면 제가 목업으로 만들어 드립니다.**

### 지금까지 보내주신 4장

| # | 화면 | 문구 | 상태 |
|---|---|---|---|
| 1 | 홈 · 이번 달 (직장인) | **이번 달 얼마 벌고 썼는지<br>한 장으로 보여요** | 좋습니다 |
| 2 | 챙길 알림 | **미루지 않게<br>때맞춰 알려드려요** | 일정 이름만 바꿔주세요 |
| 3 | 홈 · 도구 | **혼자서도 신고할 수 있게<br>순서대로 짚어드려요** | 좋습니다 |
| 4 | 가계부 달력 (빈 달) | **결제수단까지 나눠 적으면<br>카드공제 계산이 따라와요** | 그대로 씁니다 |

**3번 문구를 바꿨습니다.** 「5월 종소세, 세 단계면 끝나요」는 프리랜서 얘기라
직장인이 보면 자기 얘기가 아닙니다. 직장인 화면에도 프리랜서 화면에도 공통으로
있는 건 "순서대로 안내한다"는 것이라 거기에 맞췄습니다.

**4번은 비워 둔 화면을 그대로 씁니다.** 그래서 문구가 **적힌 것을 가리키면 안
됩니다** — 「적어 두면 그대로 이어져요」라고 쓰면 적힌 게 없어서 앞뒤가 안 맞습니다.
대신 화면에 **실제로 보이는 것**을 가리킵니다: 하단 범례의
`＋수익 · ■신용카드 · ●체크·현금 · ▲기타`. 결제수단이 갈려 있다는 게
카드공제 계산의 재료라서, 빈 달력이 오히려 "이제 여기에 적으면 된다"로 읽힙니다.

빈 화면이라 남는 여백은 목업이 흡수합니다 — 잉크 바탕 위에 놓이면 종이 질감과
빨간날이 도리어 또렷해집니다.

대안 둘:
- **월급날·카드결제일·고정지출은<br>한 번만 정해두면 돼요** — 하단 버튼 세 개를 가리킵니다
- **오늘 쓴 것부터 적어요<br>5월에 헤매지 않게요** — 오늘 날짜 밑줄을 가리킵니다

**2번 주의:** 「강아지 산책」·「점심 약속」은 실제 일정입니다. 예시로 바꿔주세요.

### 더 찍어주실 화면 — 우선순위대로

**① 종소세 진단 결과 (필수)** — 홈 2장 → 「빠진 공제 항목 찾기」 또는 「종소세 진단」 끝까지
설치 이유가 여기 있습니다. 계산이 끝나 **금액이 나온 화면**이어야 합니다.
입력 폼이 아니라 결과입니다.
> **낼 세금이 얼마인지<br>먼저 알려드려요**

**② 계산기 탭 목록 (필수)** — 하단 「계산기」
56종이 쭉 늘어선 목록. 양이 곧 메시지입니다.
> **연봉 실수령액부터 퇴직금까지<br>계산기 56종**

**③ 혜택 탭 목록** — 하단 「혜택」
54가지 정부 지원. 여기도 목록이 그대로 설득입니다.
> **몰라서 못 받는 정부 혜택<br>54가지를 모았어요**

**④ 홈 1장 · 프리랜서 또는 N잡러**
1번이 직장인이니 이건 다른 유형으로. 유형을 바꾸면 화면이 달라진다는 걸 보여줍니다.
> **직장인 · N잡러 · 프리랜서<br>고르면 화면이 바뀌어요**

4번 다시 + ①②까지면 **6장**이라 충분합니다. ③④는 여유 되실 때요.

### 찍지 말아야 할 것

- **설정·내 정보 화면.** 아무도 이걸 보고 설치하지 않습니다
- **개인 정보.** 실제 일정·실제 금액이 드러나는 화면
