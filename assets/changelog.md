# 세끌 변경 내역

이 파일 하나가 **두 곳으로 나간다** — 앱 안의 「업데이트 소식」 화면과,
Play 스토어의 「새로운 기능」(`tool/play_publish.py --from-changelog`).
두 곳에 따로 쓰면 반드시 어긋난다. 여기만 쓴다.

형식은 아래 그대로 지킬 것. `lib/core/data/changelog.dart`가 이 규칙으로 읽는다.

    ## <버전> (<빌드번호>) · <YYYY-MM-DD>[ · tax]
    - 한 줄씩. 사용자 말로. 무엇이 바뀌었는지.

`· tax`를 붙이면 **세법·복지 기준이 바뀐 릴리스**라는 뜻이다. 앱이 업데이트
카드에서 그렇게 말하고, 발행할 때 우선순위를 높게 줘야 하는 릴리스다.
안 바뀌었으면 붙이지 않는다 — 붙였다 안 바뀌면 그게 거짓말이 된다.
